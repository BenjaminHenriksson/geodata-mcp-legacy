Geodata MCP

Municipal geodata for LLM-driven analysis. SCB DeSO, SBK Stadskarta and OSM addresses over a session-scoped DuckDB spatial backend, with enforced provenance and normalized join keys. Works with any MCP-capable assistant — Claude, ChatGPT, Gemini, Qwen, and others.

01 / Connect

How to use it

Access is invite-only. If you have an invite code, point an MCP client at the endpoint below. Everything runs server-side. Your client sends natural-language questions, receives tool results (tables, layer summaries, viewer URLs, download links).

For claude.ai (recommended)

  1. In claude.ai, open Settings, Connectors, Add custom connector. Paste the endpoint URL:
    https://geo.benjaminhenriksson.com/mcp
  2. Complete the authorization flow in the popup. Enter the invite code you were given.
  3. Start a new chat. The 38 geodata tools are now available under the "Stockholm Geodata MCP" connector. Ask a spatial question and the model does the rest.

For ChatGPT, Gemini, and other web clients

Same endpoint URL — paste it into the equivalent custom-connector flow in ChatGPT, Gemini, or whichever MCP-capable client you use. Each app's connector dialog is slightly different, but the OAuth 2.1 + PKCE handshake and invite-code prompt are identical. The tool catalogue and behaviour do not depend on which model is driving them.

For Claude Code, Claude Desktop, and other CLI clients

Legacy bearer-token flow, available on request. Send the token as Authorization: Bearer <token> on every request to /mcp. The OAuth flow above is preferred; the bearer path exists for clients that do not yet implement OAuth 2.1 with PKCE — most current CLI / desktop MCP clients fall into this bucket.

02 / Inside

What the server knows

Datasets 65 pre-normalized layers SCB DeSO demographics (population, income, age, household composition), SBK Stadskarta (buildings, parks, roads, land use), OSM addresses. All reprojected to EPSG:3011, pre-filtered to kommunkod 0180 (Stockholm).
Join keys desokod, regsokod, kommunkod Every SCB table carries canonical join columns, plus a desokod_2025 bridge from 2018 boundaries. Cross-table joins do not need to know which raw column name came from which source.
Tools 38 tools over DuckDB load, filter, spatial, stats, execute_sql, frequencies, bbox_from, geocode, inspect_location, macro helpers (top_n, baseline_stats, classify, export_and_cite), reversible checkpoints with per-layer scopes, batch annotate with dry-run and coverage stats, multi-layer GPKG export with merged provenance, server-side PNG render with legend and scale bar.
Viewer MapLibre, per session A show(layers) call returns a private /view/<session> URL. Auto-refreshes as the LLM adds or styles layers. Thematic styling (categorical or linear) via the same call.
Provenance Citations per layer Every derived layer carries the union of its source dataset IDs. sources(layer) returns citations and licences; export(layer) returns a signed download URL with a short TTL.
